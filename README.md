# CC Anatomy

[Claude Code](https://claude.com/claude-code) の利用状況を可視化し、複数の Claude サブスクリプションアカウントをまとめて管理するための、macOS メニューバー常駐デスクトップアプリです（Tauri v2 + React + TypeScript）。

セッション履歴・使用量をローカルから確認しつつ、複数アカウントの切り替えや監視をメニューバーから行えます。

## 主な機能

### プロジェクト・セッションの可視化

- プロジェクト（作業ディレクトリ）別のセッション履歴一覧。claude-mem プラグイン導入済みの場合は、構造化サマリー（依頼・調査・学び・完了・次の一手）も展開表示
- セッションの会話全文をドリルダウン表示（jsonl を遅延読み込み）
- 全プロジェクト横断の全文検索（`⌘K` / `Ctrl+K`）
- プロジェクトごとの CLAUDE.md・MCP サーバー・Hooks・Rules・Agents・Skills・Commands 一覧表示
- ディレクトリツリー表示、Finder / ターミナルからのプロジェクトオープン

### アカウント管理（Keychain ベースの複数アカウント切り替え）

- 複数の Claude サブスクリプションアカウントを登録し、ワンクリックで切り替え
- ブラウザ経由でのアカウント追加・登録済みアカウントの再ログイン（別アカウントへの誤紐づけを防止）
- 60秒ごとの自動同期で、ライブセッションの資格情報を自動的に最新化
- アカウントの並び替え・表示名変更・削除

### メニューバー常駐表示

- 現在ログイン中のアカウントの使用率（5時間枠・週次枠）をメニューバーに常時表示
- 登録済み他アカウントの使用率もメニューから確認、クリックで即座に切り替え
- 使用量の常時監視（任意機能）: `claude setup-token` で発行した長期トークンを紐づけると、ログインしていないアカウントの使用率もバックグラウンドで取得

### 環境診断

- ホームディレクトリ・Desktop・Downloads の散らかり、巨大な `node_modules` やキャッシュ、未コミット・未プッシュの Git リポジトリなどをスキャンして改善提案を提示
- 選んだ項目をターミナル経由で Claude Code に修正させることも可能

### その他

- 自動アップデート（GitHub Releases 経由）

## インストール

### Homebrew（推奨）

```bash
brew install --cask o2yama/tap/cc-anatomy
```

### GitHub Releases から直接ダウンロード

[Releases ページ](https://github.com/o2yama/cc-anatomy/releases) から最新の `.dmg` をダウンロードし、`CC Anatomy.app` を `Applications` フォルダへドラッグしてください。

## 必要環境

- macOS（Apple Silicon / Intel 両対応の universal binary）
- [Claude Code](https://claude.com/claude-code) がインストール済みであること

## 初回起動の注意

<!-- 署名・公証に対応次第、この節は不要になる想定。詳細は docs/apple-signing-setup.md 参照 -->

現状、配布ビルドは Apple の署名・公証に未対応です。初回起動時に「開発元を確認できないため開けません」と表示された場合は、`CC Anatomy.app` を **右クリック（または Control キーを押しながらクリック）→「開く」** を選択してください。2回目以降は通常どおり起動できます。

## Windows について

現在 Windows には対応していません（CI 上での検証ビルドのみ実施しており、正式配布はしていません）。対応は検討中です。

## 注意事項

- 本アプリは**利用者本人が所有・契約する Claude アカウントを管理するための個人用ツール**です。アカウントの共有など、Anthropic の利用規約に反する用途を意図したものではありません。利用は各アカウントの契約条件・利用規約の範囲内で行ってください。
- 「常時監視」機能（任意）を有効にすると、対象アカウントの使用率を取得するために毎分ごく小さな API リクエスト（数トークン程度）を送信します。これは監視対象アカウントの利用量をごくわずかに消費します。不要であれば有効化しなければ発生しません。
- 認証情報（アクセストークン等）は macOS の **Keychain にのみ**保存され、Anthropic の公式 API 以外へ送信されることはありません。
- 本アプリは非公式のツールであり、Anthropic とは無関係です。
